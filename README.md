# ☕ KASA'S CAFE - Python

A simple and beginner-friendly Python console application for ordering items from KASA'S Cafe and calculating the total order value.


## 📌 Project Description

The program displays the available menu items along with their prices, accepts the customer's order, provides an option to add one more item and calculates the total order value.

## 🍽️ Menu

| Item | Price |
|---|---:|
| Tea | ₹30 |
| Coffee | ₹40 |
| Green Tea | ₹50 |
| Osmania Biscuits | ₹20 |

## ✨ Features

- Displays the KASA'S Cafe menu.
- Allows the customer to select an item.
- Calculates the price of the selected item.
- Allows the customer to add a second item.
- Calculates the total order value.
- Displays an error message when an invalid item is entered.
- Simple and beginner-friendly console interface.

## 🛠️ Technologies Used

- Python 3
- Python dictionaries
- Conditional statements (if/else)
- User input (input())
- Arithmetic operators
- Formatted strings (f-strings)
